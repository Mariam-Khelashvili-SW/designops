Figma

Used to read file comments and last-updated metadata for tracked projects (Weekly health → Fetch from Fairwind / Jira, and the probe below). Everything Figma-related is saved here in the database — nothing is read from .env. Auth preference: Connect Figma when connected, otherwise the personal access token.

1. OAuth app (for Connect Figma)

Create an app at figma.com/developers/apps, publish it private for your team, and enable scopes file_comments:read, file_metadata:read, current_user:read. Add the redirect URI below on the app’s OAuth credentials page (must match exactly). Client ID + secret identify this DesignOps app to Figma; they are not a user token.
